# Простая инструкция: как пользоваться системой сверки БУ-ПУ

Эта инструкция рассчитана на любого пользователя — программировать не нужно.

---

## Шаг 1. Установить Python

Нужен **Python 3.10 или новее**. Проверить, установлен ли он:

```bash
python --version
```

Если команда не найдена — скачайте Python с https://python.org и при установке
на Windows отметьте галочку **«Add Python to PATH»**.

---

## Шаг 2. Скачать проект и установить зависимости

```bash
git clone <адрес-репозитория>
cd npf
pip install -e .
```

Команда `pip install -e .` один раз установит всё необходимое
(pandas, openpyxl, pyyaml).

---

## Шаг 3. Запустить меню

**Windows:** дважды кликните `run.bat` (или в консоли наберите `run.bat`).

**Linux / macOS:**

```bash
./run.sh
```

Появится меню:

```
1. Демо: сгенерировать тестовые данные и выполнить сверку
2. Сверка по моим файлам (из каталогов ПУ и БУ)
3. Диагностика парсинга (проверка распознавания файлов)
4. Где разместить входные файлы
5. Выход
```

---

## Шаг 4. Попробовать на тестовых данных

Введите **`1`** и нажмите Enter.

Система сама создаст примеры файлов, выполнит сверку и сохранит результаты в
папку **`output`**. Откройте там файл **`Сверка_БУ_ПУ.xlsx`**.

---

## Шаг 5. Сверить свои файлы

1. В меню выберите пункт **`4`** — система покажет, в какие папки класть файлы.
2. Положите ваши файлы:
   - в папку **`data/ПУ`** — выплаты, пенсионные и целевые взносы, страховой резерв;
   - в папку **`data/БУ`** — файл «397.03 Страховой резерв …» и файл «НПО_….json».
3. Вернитесь в меню и выберите пункт **`2`** — сверка по вашим файлам.

> Имена файлов не обязаны совпадать точь-в-точь — достаточно, чтобы в названии
> была ключевая фраза (например, «Целевые взносы ЮЛ»). Регистр букв и дата в
> названии значения не имеют. Лишние файлы система игнорирует сама.

---

## Шаг 6. Посмотреть результат

В папке `output` появятся три файла:

| Файл | Что это |
|---|---|
| `Сверка_БУ_ПУ.xlsx` | **Главный отчёт.** Лист «Свод» — суммы по БУ и ПУ и расхождения; лист «Детализация» — расхождения по дням. |
| `Саммари_БУ_ПУ.json` | Краткие **обезличенные** итоги (без персональных данных) — для автоматической генерации текстового описания. |
| `Промт_для_LLM.txt` | Готовый текст-запрос для нейросети, которая напишет краткое описание отчёта. |

В отчёте расхождения выделены цветом. Если расхождений нет — соответствующие
колонки пустые.

---

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| «Папки не существуют» | Программа создаст их сама — положите файлы и запустите снова. |
| «Файлы не найдены» | Проверьте, что файлы лежат именно в `data/ПУ` и `data/БУ`. |
| Файл не распознан | Проверьте пункт меню `3` (диагностика) — он покажет, какие файлы прочитаны, а какие пропущены и почему. |
| Неверные суммы | Убедитесь, что в файле нужная колонка с суммой (см. README, раздел «Реестр файлов → показатели»). |

Полное описание возможностей — в файле **README.md**.
